## Core design principles

1. **ST8WRX is the product. Buzz is the inherited collaboration substrate.**
2. **Humans, agents, compute, IP, and capital are first-class project inputs.**
3. **Activity is evidence, not automatic ownership.**
4. **Contribution, revenue participation, legal equity, and tokens are separate concepts.**
5. **AI can assess contribution but cannot unilaterally determine ownership.**
6. **High-frequency collaboration remains off-chain.**
7. **BSV is used where durable proof, settlement, assets, or contracts add real value.**
8. **Private project data stays private by default; public chains receive proofs or deliberately published artifacts.**
9. **Project tokens are optional and must have real application utility.**
10. **The platform token, if launched, must be justified by a working network economy rather than speculation.**

## Implementation sequence

Current planned sequence:

1. contribution evidence vertical slice
2. BSV testnet provenance receipt
3. project contribution policy + governance
4. Buzz Mesh metering and compute receipts
5. wallet identity binding and payments
6. bounty/milestone escrow
7. project treasury and revenue distribution
8. ST8 Market
9. project token launcher
10. network token only after utility/economics are proven
